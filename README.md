# DeepTime Sauropsida

现生蜥形纲演化时间树项目，按“鸟类到目，其余到科”的粒度展示龟鳖、喙头蜥、鳄类、鸟类与有鳞类的系统关系。

## 当前状态

- 数据文件：`data/data.js`
- 末级节点：126
- 内部分类节点：64
- 层级策略：鸟类到目，其余到科；对节点过密的支系补入下目、总科等中间层

## 数据基准

- Reptile Database
- IOC World Bird List
- 部分高阶时间参考近年的蜥形纲、龟鳖类与鸟类系统发育研究

## 说明

- 高阶节点时间优先采用常见冠群分化时间
- 末级节点时间目前是为可视化整理的近似冠群时间
- 图像资源暂未系统补齐，当前阶段以树结构和节点数据为主
