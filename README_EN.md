# DeepTime Sauropsida

An evolution-tree project for living Sauropsida, organized at order level for birds and family level for the remaining extant sauropsid lineages.

## Current Scope

- Data file: `data/data.js`
- Terminal nodes: 126
- Internal clades: 64
- Hierarchy policy: birds to order, all others to family, with added infraorders and superfamilies for crowded branches

## Data Basis

- Reptile Database
- IOC World Bird List
- Recent phylogenetic studies on major sauropsid lineages for higher-level crown ages

## Notes

- Higher clades prioritize literature-based crown divergence times
- Terminal-node ages are currently approximate crown-age estimates for visualization
- Image assets are not yet fully curated; the present milestone focuses on tree structure and node data
